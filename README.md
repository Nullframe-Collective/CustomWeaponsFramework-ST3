# CustomWeaponFramework

Custom weapons and inventory integration for Slendytubbies 3 Multiplayer and NullServers.

Requires Slendytubbies 3 Multiplayer (IL2CPP), MelonLoader and a compatible NullServers build. Build with the .NET 10 SDK targeting .NET 6; set the GamePath MSBuild property to your game folder. Install the resulting DLL in the game's Mods folder.

See [technical notes](docs/DETAILS.md) for details.
